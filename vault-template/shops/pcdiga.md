# PCDiga

PC components, laptops, peripherals, gaming.

## Search and products
- Header search box; filter by category for components (CPU, GPU, RAM…).
- Stock states matter: "Em stock" ships fast; "Disponível por encomenda" / "Sob consulta" can
  take weeks — always report it.
- For components, confirm compatibility details from the user's request (socket, size, wattage);
  ask when unsure.

## Cart and checkout
- "Adicionar ao carrinho" → cart → "Finalizar compra" (SPEND approval) → shipping (courier) or
  store pickup → saved payment.
