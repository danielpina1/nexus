# Worten

Electronics, appliances, phones, gaming (Sonae).

## Login
- Worten account (can be the same e-mail as other Sonae sites, but the login is separate).
  Log in once in the `worten` profile.

## Search and products
- Search URL or header box; filter by brand/price on the left; sort "Preço" if comparing.
- Check on the product page: price, "Vendido por" (Worten vs marketplace seller), stock
  ("Disponível", "Últimas unidades", "Esgotado"), delivery estimate, store pickup availability.
- Extended warranty / insurance ("Worten Resolve", "Garantia extra") is offered as an add-on:
  never add it unless the user asked.
- Old-appliance collection and installation are paid extras for large appliances — ask.

## Cart and checkout
1. "Adicionar ao carrinho" → skip upsell pop-ups ("Não, obrigado") → cart.
2. "Finalizar encomenda" (SPEND approval) → delivery or "Levantamento em loja" → saved payment
   (cards, MB WAY, Multibanco reference).
3. Multibanco reference payments complete later: report the reference shown, do not pay it.
